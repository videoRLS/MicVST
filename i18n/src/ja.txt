MicVST の使い方

1)  仮想オーディオケーブルをインストール
    無料の VB-Cable がおすすめです: vb-audio.com/Cable。MicVST が自動で見つけます。

2)  デバイスを選択（ウィンドウ上部）
    入力  =  あなたのマイク
    出力  =  仮想ケーブル（例:「CABLE Input」）

3)  プラグインチェーンを組む
    - 「+ プラグイン」で、すべての VST3 エフェクトと内蔵ツールをメーカー別に
      まとめた検索可能な一覧が開きます。必要なエフェクトを追加してください
      （EQ、ノイズ除去、コンプレッサー...）。
    - ステレオにしたい位置に「Mono -> Stereo」を追加します。それより前は
      モノラルで動作します（CPU 負荷が軽い）。「Stereo -> Mono」もあります。
      モノラルで終わるチェーンはケーブルの両チャンネルに送られます。
    - 「ゲイン」（内蔵）は音量を -30 から +12 dB の範囲で下げ／上げします。値は
      行のスライダーで変更します。音割れを防ぐためリミッターの前に置いてください。
    - 「自動ゲイン」（内蔵）は声をリアルタイムで分析します: 普通に話すとピークは
      約 -20 dBFS、叫ぶと約 -15 dBFS になり、どのピークも -10 dBFS を
      超えません。ゲインは 0 から +6 dB の間で変化し、
      無音のときは保持されます（ノイズゲートなし）。チェーン内のどこへでも
      移動でき、行のチェックボックスでオン／オフできます。
    - 左のハンドルをドラッグして並べ替え、ごみ箱で削除します（確認あり）。
    - プラグイン名をダブルクリックするとそのウィンドウが開きます。
    - 「設定 > プラグイン」で別の場所にある VST3 プラグインを追加できます。
    - 内蔵エフェクト（EQ、ディエッサー、サチュレーション、リミッター、LUFS メーター...）は
      一覧の「内蔵 - ...」見出しの下にあり、名前をダブルクリックすると設定が開きます。
    - 「プリセット」一覧はチェーン全体を一度の選択で切り替えます: 工場出荷のプリセットは
      内蔵エフェクトだけを使います。「保存」は現在のチェーン（VST3 プラグインと
      その設定を含む）を自分のプリセットとして保存します。「前のチェーン」で直前の選択を取り消せます。

4)  好きなプログラムで使う
    Discord、OBS、Zoom などで、マイクとして「CABLE Output」を選びます。

5)  途切れない音声
    マイク、プラグインチェーン、ケーブルはそれぞれ独立して動作し、その間の小さな
    安全マージンが一時的な負荷の山を吸収します。「自動」は必要に応じてこの
    マージンを自分で広げます。下の行には遅延、CPU 負荷、すべての途切れが表示されます。
    「チェーンが重すぎます」と表示されたら、現在の負荷ではプラグインが追いついて
    いません: 品質設定（オーバーサンプリング、先読み）を下げるか、
    バックグラウンドの重いプログラムの優先度を下げてください。
    「プロセス優先度」（「標準」推奨）は MicVST のウィンドウとデバイス処理を
    他のプログラムより優先します。音声はどの設定でも Windows のリアルタイム
    オーディオ優先度で処理されます。

6)  以上です
    設定は自動で保存されます。ウィンドウを閉じても、MicVST は時計の横の
    アイコンとして動作を続けます（オプションはアイコンを右クリック）。
    「設定」で「Windows の起動時に開始」をオンにすると、Windows の起動時に静かに開始します。
